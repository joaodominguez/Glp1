# Rotina Search Console (manual)

Sem automação nesta versão — revisar mensalmente na conta Google do projecto.

## Passos

1. Abrir desempenho → filtrar últimos 28 dias  
2. Ordenar por impressões; notar queries com CTR baixo ou posição 10–30  
3. Para cada oportunidade:
   - FAQ nova, ou  
   - artigo «Na prática», ou  
   - reforço de title/meta + internal links  
4. Registar a decisão num commit ou nota editorial  
5. Após publish, confirmar URL no sitemap e no live  

## Apostas actuais

- Rybelsus / Rybelsus Portugal  
- Comparações de nomes comerciais  
- Stock / preço / comparticipação  
- FAQ de efeitos e mitos  

## Não fazer

- Otimizar para queries de compra ilegal ou clínicas «milagre»  
- Keyword stuffing em páginas YMYL
